-- =====================================================================================
-- 사용자 시뮬레이션 조건 저장 테이블 (4단계 신설 초안) — DBA 승인 필요
--
-- 왜 신규 테이블인가
--   기존 TN_PM_SMLT_*_ATRB 계열은 <자원>_ATRB_ID 로 묶인 CAST 리소스 마스터이고,
--   TN_PM_SMLT_STNG.*_RSRC_ID 가 그것을 참조한다. 즉 여러 시뮬레이션이 같은 ATRB 행을
--   공유하므로, 사용자가 편집한 조건을 거기에 쓰면 다른 시뮬레이션 결과가 오염된다.
--   (docs/db/06-decisions.md D7 / 04-screen-table-mapping.md 3.4 참고)
--   또한 *_ATRB 계열에는 쓰기 SQL 이 하나도 없고 DDL 도 확보되지 않았다 (G22).
--   따라서 사용자 조건은 SMLT_ID + TMNL_ID 로 격리된 아래 테이블에 저장하고,
--   CAST 리소스 발행 시점에 여기서 읽어 ATRB 행을 만든다.
--
-- 공통 규칙 (docs/db/02-naming-convention.md)
--   - 감사 컬럼 6종 고정. INSERT 는 FRST_* 3종, UPDATE 는 LAST_* 3종.
--   - 타입은 VARCHAR2(n) / NUMBER(p,0) / TIMESTAMP(6) 만 쓴다.
--   - PK 이름은 <TABLE>_PK. 데이터 TSDPM01 / 인덱스 TSIPM01.
--   - 모든 테이블·컬럼에 한국어 COMMENT ON.
--   - TMNL_ID 는 DB 코드계(P01/P02/P03)다. 화면의 T1/T2 변환은 TerminalKind 가 한다.
-- =====================================================================================
