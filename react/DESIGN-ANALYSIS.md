## 2. 화면 셸 (4개 화면 공통 골격)

```
┌──────────────────────────────────────────────────────────────┐
│  헤더 70px : [타이틀 / 서브타이틀]  [중앙 검색바]  [우측 액션]  │
├────┬─────────────────────────────────────────────────────────┤
│LNB │                                                         │
│레일│                     본문 (한 화면 고정)                   │
│79px│                                                         │
│    │                                                         │
│[⎋] │                                                         │
└────┴─────────────────────────────────────────────────────────┘
```

### 셸 토큰 (`src/common.css` `:root`)

| 토큰 | 값 | 의미 |
|---|---|---|
| `--pm-header-h` | `70px` (≤900h: `60px`) | 헤더/GNB 높이 |
| `--pm-shell-x` | `24px` | 본문 좌우 바깥 여백 |
| `--pm-shell-top` | `16px` (≤900h: `12px`) | 헤더 ↔ 본문 |
| `--pm-shell-bottom` | `20px` (≤900h: `14px`) | 본문 ↔ 하단 |
| `--pm-shell-gap` | `16px` | LNB ↔ 본문 |
| `--pm-lnb-w` | `79px` | LNB 레일 폭 |
| `--pm-lnb-open-w` | `250px` | LNB 펼침 패널 폭(본문 위를 덮음) |

- `.pm-shell { height:100vh; overflow:hidden }` — **세로 스크롤 없음**. 각 화면이 남은 높이를 flex로 나눠 먹는다.
- 가로만 `overflow-x:auto`. 최소 너비 기준은 맵 형태 조회 **1440px**.
- 대시보드는 별도로 `useFitToScreen` + `--scale` 로 본문 전체를 축소해 한 화면에 맞춘다.

### LNB 레일

- 상단 그룹 4개: 일일 시뮬레이션(chart) / 사용자 시뮬레이션(user) / 시뮬레이션 모니터링(monitor) / 시설물 매핑(pin)
  → 활성 시 **보라 원형 배경 + 흰 아이콘**
- 구분선(hairline) 아래 하단 그룹 5개: 요약보기(grid) / 맵형태보기(map) / 체크인카운터(pass) / 셀프체크인·백드롭(luggage) / 출국장(planeDep)
  → 활성 시 **아이콘 색상만** 강조
- 레일 최하단: 로그아웃/토글 아이콘. 펼치면 250px 패널 + 사용자 정보(부서/이름) 노출.
- 아이콘 온리 → 라벨은 툴팁.

### 3.3 배경 그라디언트 (이 UI의 시그니처)

카드/패널이 **단색이 아니라 미세한 다중 스톱 그라디언트**로 채워져 유리판 같은 질감을 낸다.

```css
--panel-bg: linear-gradient(158deg, #efeef6 0%, #f8f8fc 32%, #fdfdfe 66%, #f3f7fa 100%);
--card-bg:  linear-gradient(140deg, #f4f3f9 0%, #edecf5 42%, #e6e6f2 100%);
--box-blue: #eaf3ff;   /* T1 계열 옅은 박스 */
--box-mint: #f0fffc;   /* T2 계열 옅은 박스 */
--hair: 1px solid rgba(255,255,255,.65);  /* 카드 안쪽 하이라이트 테두리 */
```

배경에는 **터미널 실루엣 워터마크**(`BgDeco`)가 아주 옅게 깔린다(3~7.png 좌측 패널, 2.png 맵 전체).

### 3.4 그림자 / 라운드

```css
--sh:     0 1px 2px rgba(46,50,94,.04), 0 6px 16px rgba(46,50,94,.06);
--sh-lg:  0 1px 3px rgba(46,50,94,.05), 0 10px 30px rgba(46,50,94,.08);

--shadow-modal: 0 18px 50px rgba(35,45,90,.25);
```

- 큰 패널 20px / 카드 18px / 작은 박스·버튼 10~14px / 알약·탭 **fully rounded**
- 그림자는 전부 **푸른 기 도는 저채도**(순수 검정 그림자 없음)

## 5. 공통 컴포넌트 패턴

### 5.1 헤더 (모든 화면)

- **좌**: `PM 예측관리` (bold) + ` / 화면명` (regular) — 한 줄, 구분자 `/`
- **중앙**: 흰 알약형 검색 바
  - `기준일자` 라벨 + 캘린더 아이콘 + 날짜 + (화면별) 시/분 스피너 또는 라디오
  - 우측 끝에 **보라 원형 검색 버튼**(돋보기)
  - 변형: 1.png = 일자+시:분 / 2.png = 일자+T1·T2 라디오 / 3~7.png = 일자만 / 8.png = 시작~종료 일시 2세트
- **우**: 화면별 액션
  - 1.png: `사용자 시뮬레이션` 보라 알약 버튼 + 우측 메타(마지막 계산 / 재계산 예정, 시계 아이콘)
  - 2.png: 운항/여객 총계 텍스트만
  - 3~7.png: `▶ 시뮬레이션 실행` 보라 알약 + `시뮬레이션 이력` 텍스트 링크
  - 8.png: 없음

### 5.2 탭 (사용자 시뮬레이션)

- 화면 상단 중앙, **연회색 알약 트랙 안에 5개 탭**
- 활성 탭 = 흰 배경 + 보라 텍스트 + 보라 1px 테두리 (pill)
- 비활성 = 투명 배경 + 회색 텍스트
- 순서: 운항편/여객수 · 체크인 카운터 · 셀프체크인/백드롭 · 출국장 · 보안 검색대

### 5.3 T1 / T2 좌우 2분할 (사용자 시뮬레이션 전 탭 + 모니터링)

전 탭이 동일 구조:

| | 좌측 (T1) | 우측 (T2) |
|---|---|---|
| 패널 배경 | 밝은 그라디언트 + 워터마크 | 회색 톤 (비활성 느낌) |
| 터미널 아이콘 | 파랑 라운드 스퀘어 | 회색 라운드 스퀘어 |
| 요약 바 | 옅은 파랑 (`--box-blue`) | 옅은 회색 |
| 데이터 색 | 보라/파랑 | **무채색(회색~검정)** |
| 하단 버튼 | `현재상태 저장` 보라 알약 | 없음 |

> 즉 **선택된 터미널만 컬러, 나머지는 그레이스케일** 로 상태를 표현한다.
> 1.png 대시보드에서는 반대로 T1=블루 그라디언트 카드, T2=옐로우→그린 그라디언트 카드로 **둘 다 컬러**.

### 5.4 요약 바 (탭 상단)

`[터미널 아이콘] [ 라벨 값  라벨 값  라벨 값 ]  [지도 아이콘 버튼]` — 라벨은 회색 작은 글씨, 값은 굵고 큰 글씨. 배경은 옅은 파랑 라운드 박스.

### 5.5 24시간 타임라인 슬롯 바 (4·5·6.png 반복)

```
□□□□□□■■■■■■■■□□■■■■■■□□
00:00   04:00   08:00 … 24:00
```

- 24칸 세그먼트, 각 칸 라운드 사각형(4~6px)
- 선택 = `--pm-primary-light` 보라 / 비선택 = 연회색 / T2쪽은 회색
- 아래 4시간 간격 눈금 라벨(00:00 / 04:00 / … / 24:00)
- 상단에 `선택 범위 06:00 ~ 14:00, 16:00 ~ 22:00` 텍스트로 구간 복수 표기

### 5.6 아일랜드 피커 (4·5.png 하단)

`A B C D E F G H J K L M N` 알약 버튼 행. 활성 = 보라(좌)/진회색(우) 채움, 비활성 = 연회색.

### 5.7 테이블

- 헤더: 옅은 회색 배경, 회색 중간 굵기 텍스트, 라운드 상단
- 행: 흰 배경 + 1px 하단 라인, hover/선택 시 옅은 배경 + **점선 테두리**(1.png `04:00` 행)
- 상태 텍스트: `완료` 초록 / `진행중` 회색
- 행 액션: `보기` 아웃라인 알약 버튼(비활성 시 회색 채움)
- 스크롤 영역은 `.scroll-area` (`overscroll-behavior: contain`)

### 5.8 폼 컨트롤

- **드롭다운**: 흰 알약 + `⌄` (6.png `사용`/`미사용`)
- **체크박스**: 정사각 라운드, 미체크 시 회색 테두리
- **라디오**: 원형, 선택 시 보라 도넛
- **스텝퍼**: `‹ 10% ›` 좌우 화살표 + 중앙 값 (3.png)
- **시간 입력**: `[00] 시 [00] 분 – [00] 시 [00] 분` 작은 박스 인풋 (7.png)
- **추가/삭제**: `+ 추가` 보라 채움 알약 / `− 삭제` 흰 아웃라인 알약

## 6. 화면별 특징

### 6.1 대시보드 (1.png)

- **상단 KPI 행 5블록**: 일일 운항계획 / 시간대별 출발여객 / 요일 속성 / 기상정보 / 바로가기 2×2 타일
  - 바로가기 타일: 활성 1개만 보라 채움(터미널 여객수), 나머지는 옅은 파랑
- **하단 좌우 T1/T2 대칭 블록**:
  - 세로 긴 그라디언트 배지(터미널 아이콘) — T1 블루, T2 옐로우→그린
  - 지난주 동요일 대비 증감 + 탑승률 도넛형 박스
  - 피크시간 박스(AM 10:00 / 총 대기인원 / 최대 대기시간 / 시간당 처리인원)
  - **예측 vs 실적 라인 차트**: 예측=빨강 실선+원마커, 실적=파랑 점선+원마커, 피크 시각에 **빨간 세로 바** 오버레이
  - 섹션 헤더 `▌터미널에 여객수가 [가장 많을 때]` + 우측 `요약 / 출국장` 토글 알약
  - 결과 배너: **좌→우 그라디언트 풀폭 바**(T1 블루→시안, T2 옐로우→그린), 흰 굵은 텍스트로 `2026- 07-10 FRI 10:00 AM`
  - 요약 카드 2개(운항편/여객) + 요약정보 박스(대기인원수/최대대기시간/시간당처리인원)
  - 체크인카운터 · 출국장 캐러셀 카드: 좌우 `‹ ›` 화살표, `추천` 빨간 배지, 도넛 게이지 2개, 하단 알파벳/숫자 상태 칩(초록/노랑/빨강/회색)
- T2쪽은 같은 자리에 **테이블 뷰**(시간대/승객수/대기시간/처리시간/비율)로 전환된 상태 — 즉 `요약 ↔ 출국장` 토글로 차트↔테이블 전환.

### 6.2 맵 형태 조회 (2.png)

- 상단 **혼잡 알림 바**: 좌측 빨간 `!` 원형 + `매우혼잡`, 우측으로 혼잡 시설 목록 가로 나열(`체크인카운터 M11 (3개 부스 OPEN)` …)
- **상단 도넛 카드 행**: `05:30-23:30` / `하루 18시간 운영`, 24시간 원형 게이지(0시/6시/12시/18시 눈금), 비운영 카드는 회색 처리
- **터미널 아치 맵**: 배경 워터마크 위에 시설 마커 배치
  - 검정 라운드 사각 = 출국장 번호(1~6)
  - 컬러 라운드 사각 = 체크인 아일랜드(A~N) — 초록/노랑/빨강 = 혼잡도
  - 회색 작은 사각 = 부속 번호(1~14)
  - 우상단 안내: `해당구역을 클릭하세요`
